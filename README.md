# DriveAnalytics

スマートフォンのセンサーを使用して車両の乗り心地を評価するPWAアプリケーション。

## 機能

- 位置情報のリアルタイム取得と表示
- 加速度センサーによる振動測定
- マイクを使用したノイズレベル測定
- データのリアルタイム表示とログ記録

## 使い方

1. モバイルブラウザでアプリにアクセス
2. 「計測開始」ボタンをタップしてセンサーデータの収集を開始
3. 乗り心地データを確認
4. 「計測停止」ボタンをタップして計測を終了

## 開発環境のセットアップ

```bash
# ローカルサーバーの起動
npx http-server -c-1
```

## 注意事項

- センサーへのアクセス許可が必要です（位置情報、加速度センサー、マイク）
- デバイスがHTTPS上で実行されている必要があります（一部のセンサーAPI用）
- スマートフォンは車内で安定した場所に固定してください
