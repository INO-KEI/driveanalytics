# deta/ 計測データ蓄積フォルダ

DriveAnalyticsで計測したCSVを蓄積し、車種・条件をまたいで比較しながら解析ロジックの精度を上げていくための置き場所です。

## 運用ルール

1. アプリで計測 → 停止 → 「CSV保存」または「メールで送る」で書き出す。
2. ファイル名は `driveanalytics-<車種>-<YYYYMMDD-HHMMSS>.csv`（車種未設定の場合は車種部分なし）。**サブフォルダには分けず、`deta/` 直下にすべて置く。車種の識別はファイル名で行う。**
3. 書き出したファイルをClaudeとの会話にアップロードする。Claudeがその場で`deta/`直下にコピーして保存する（2026-09-22以降のアップロード分から。それ以前にアップロードした分は未整理）。
4. Claudeに解析の変更・チューニングを依頼するときは、関連する過去データがこのフォルダにあれば併せて読み込んでから作業する。

## CSVのメタ情報（ファイル先頭の `#` 行）

計測条件は毎回アプリの「計測条件」画面で入力し、CSVの先頭に埋め込まれる。

| 行 | 内容 |
|---|---|
| `# vehicle` | 車種（クラウンスポーツ／シエンタ／自由入力） |
| `# powertrain` | 動力方式（EV / HV / ICE） |
| `# road_type` | 道路種別（市街地／郊外／山間部／高速道路） |
| `# mic_source` | 使用マイク（スマホ本体／車載マイク） |
| `# device` | 使用端末（iPhone 16e / iPhone SE2 / 自由入力） |
| `# drive_mode` | ドライブモード（Eco/Normal/Sport、地図パネルのチップで選択） |

さらに `# phase_band,<ID>,<日本語ラベル>,n=...,vibration=...,shake=...,transitions=...` として、走行フェーズ別（下記）の集計も入っている。

## 走行フェーズ分類（`drive_phase` 列 / `# phase_band` 行）

GPSの速度・方位変化から、1秒ごとのサンプルを以下のいずれかに分類している（[js/vehicle.js](../js/vehicle.js) の `updateDrivePhase()`）。

- `LOW_SPEED_ACCEL`（低速域加速） / `HIGH_SPEED_ACCEL`（高速域加速）
- `CRUISE`（巡行）
- `HIGH_SPEED_DECEL`（高速域減速） / `LOW_SPEED_DECEL`（低速域減速）
- `INTERSECTION_RIGHT`（交差点右折） / `INTERSECTION_LEFT`（交差点左折）
- `CURVE`（左右旋回）
- `STOPPED`（停止）

低速/高速の境界、旋回とみなす角度・速度のしきい値は初期値（`js/vehicle.js` の `CONFIG.phase*`）であり、このフォルダにデータが蓄積されて実際の交差点通過・カーブのパターンが分かってきたら調整する前提。

## 注意

- 古い計測（この仕組み導入前のCSV）にはこれらのメタ情報が入っていない。比較には使えるが、車種・条件は別途メモしておくこと。
- CSVそのものに走行位置（緯度経度）が含まれるため、取り扱いに注意する。
